# CRANEO 3D v4 theme

A theme for the Claude desktop app (Code tab), based on the CRANEO 3D v4 design system.

- **Light:** sticker-sheet paper, cobalt accent.
- **Dark:** cobalt night, cadmium accent.
- **Backdrop:** a slow-drifting sticker sheet (ruler, dot field, four pigments). It stops under reduced motion.

## Install

In the Claude desktop app: Plugins → Add marketplace → `CRAN3O/craneo-3d-v4-theme`, then install `craneo-3d-v4` and start a new local session in the Code tab.

Or from a Claude Code session:

```
/plugin marketplace add CRAN3O/craneo-3d-v4-theme
/plugin install craneo-3d-v4@craneo-local
```

Requires Claude Code 2.1.324 or newer.
